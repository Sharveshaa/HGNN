# HGNN Phishing Detection System

A multimodal phishing detection system using Heterogeneous Graph Neural Networks (HGNN), Meta-Path Attention, Temporal GRUs, Cross-Modal Fusion, and Explainability.

## Project Phases
1. **Phase 1**: Project Setup
2. **Phase 2**: Dataset Preparation
3. **Phase 3**: Heterogeneous Graph Construction
4. **Phase 4**: Feature Extraction
5. **Phase 5**: HGNN Development
6. **Phase 6**: Meta-Path Attention
7. **Phase 7**: Temporal Modeling
8. **Phase 8**: Cross-Modal Fusion
9. **Phase 9**: Explainability
10. **Phase 10**: Backend Development
11. **Phase 11**: Frontend
12. **Phase 12**: Deployment
